# 금산마을: 네 단계로 배우는 우리 동네 수호대

기존 사용자의 세부 구현 위임(합리적으로 정해 진행)과 최신 네 레벨 요구를 적용한다. 기존 Three.js/Vite/브라우저 저장을 유지한다.

## 목표와 접근
- 기존 자유 활동은 순서 있는 레벨로 바꾼다. 레벨 완료 전에는 이후 활동을 UI와 실제 처리 함수에서 모두 막는다. 숨기기만 하거나, 전시 업로드·도감·학교 안건·스탬프 메뉴로 우회할 수 있게 두지 않는다.
- 자유 모드와 순차 모드를 병행하는 대안은 진행 조건이 불명확해지고 같은 버그가 반복되므로 채택하지 않는다. 기존 기능에 중앙 진행 판정을 연결하는 한 가지 방식을 사용한다.
- 사용자가 이미 위임한 세부 선택: 레벨 1은 회의 읽기 확인 + 안건 선택/실천 약속 + 첫 실천 체크로 완료한다. 일주일을 기다리지 않는다. 이후에도 서울 시간 기준 이번 주의 날짜별 체크·메모를 수정할 수 있다.

## 레벨과 보상
1. 학교: 회의 결과 읽기, 이번 주 실천 계획, 첫 체크. 준비 단계로 스탬프는 없음.
2. 통학로: 안내 길 연결과 주택가 쓰레기 수거·분류. 마을 스탬프.
3. 금호지: 동물 첫 자기소개, 기존 전설 대화 전체 읽기, 전용 퀴즈. 이야기 스탬프.
4. 남강 생태 지도: 그림 업로드/배경 편집, 생물 이름, 내가 지킬 실천 약속, 남강 전시 등록. 생태 스탬프. 세 스탬프로 수호대 완료.
호수 쓰레기·연습 표본 활동은 유지하되 레벨 4 완료를 대신하지 않는다.

## 표현과 안내
- 건물의 공중 Sprite 이름표를 없애고 앞면의 실제 간판과 입구 표지판으로 표시한다.
- 동물 머리 위 이름표도 없앤다. 첫 허용 대화에서 소개하고 기록한다. 레벨 3 전에는 현재 레벨을 먼저 마치라는 짧은 안내만 한다.
- 실제 금호지 서식이 미확인인 수달/학을 실제 서식종으로 단정하지 않는다. ‘이 게임에서 금호지 곁에 사는 가상의 친구’로 말한다.
- 현재 해야 할 대상만 3D 빛 고리/기둥과 지도 표시로 안내한다. 실내에서는 게시판/출구를 가리킨다. ‘움직임 줄이기’에서는 깜빡임 없이 고정 표시한다.
- 남강 구역은 수업용 축약 마을의 별도 전시 공간이다. 작품, 이름, 보호 약속을 실제 3D 전시판 및 도감/지도/상세에 함께 표시한다.

## 저장과 호환
새 journey 상태에 학교·주간 체크·첫 만남·전시 작품 ID를 저장한다. 기존 그림·편지·퀘스트·전설 기록을 삭제하지 않는다. 이전 저장은 학교부터 새 순서를 안내하고, 이후 단계에서 기존 완료 기록은 인정한다. 기존 그림은 이름과 보호 약속을 보완하여 전시할 수 있다. 가져오기만으로 학생 레벨을 완료시키지 않는다. 마지막 자신의 전시 작품을 삭제하면 레벨 4로 돌아간다.

## 검증과 범위
중앙 단계 판정/주간 날짜/잠금/진행 저장/전시 삭제를 Node 테스트로, 실제 WebGL/UI 순차 플레이와 잠금 우회·한글 조작·그림/편지·교사 편집·모델 실패를 Playwright로 검증한다. 실제 동물 서식 사실 검증과 서버 학급 공유는 이번 변경 범위에 넣지 않는다.
