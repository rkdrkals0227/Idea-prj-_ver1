# 마을 음악과 상황별 효과음

사용자 요청: 끊김 없이 이어지는 평화로운 창작 BGM, 볼륨 조절, 실제 걷기/문제 판정/책 넘김/전체 완료의 효과음, 축하 화면. 기존 Three.js/Vite·세 미션·확대 기능 유지. 별도 API/외부 음원 없음.

1. `scripts/compose_bgm.py`로 16마디 창작곡을 합성하고 `public/audio/village-day.ogg` 및 WAV 대체 파일을 만든다. 코드가 악보·음색 소스이며 원곡 모방 없이 어쿠스틱 플럭·벨·패드·베이스를 조합한다. 루프 끝의 잔향은 시작에 순환 합산한다.
2. `src/audio.js`는 Web Audio 단일 컨텍스트, 루프 AudioBufferSource, 별도 음악/효과음 GainNode를 관리한다. 첫 시작 클릭에서 unlock, 중복 로드/재시작 방지, 탭 비활성 시 suspend, 음소거/복귀·실패 후 재시도와 안내를 제공한다. 효과음은 짧은 합성 음과 노이즈이며 재생 속도를 제한한다.
3. 설정/로컬 저장에 기본 소리 켜짐과 음악·효과음 볼륨을 추가한다. 범위를 검증하고 새 게임에서도 선호를 보존한다. 음악 재생 상태 및 재시도 버튼을 설정에 제공한다.
4. World는 실제 좌표가 변하는 걷기만 알린다. 퀴즈/점자블록/분리배출의 판정에서만 정답·오답을 재생한다. 도서관/전설/필수 설명의 실제 페이지 전환에 종이 소리를 연결한다. 최종 퀴즈의 처음 성공에만 축하 팡파르·부드러운 폭죽을 재생하고, 성공 카드에 짧은 비점멸 폭죽/색종이를 표시한다. 움직임 줄이기는 정적인 장식으로 대체한다.
5. 실제 Web Audio 브라우저 검사: 사용자 클릭 전 미재생, 음악 파형·루프·동일 소스 유지, 볼륨/음소거/복귀/저장, 이동·대화 중 발소리 제한, 정오답·페이지·완료 효과 이벤트, 중복 축하 방지, 로드 실패 복구. 단위 검사와 빌드 후 정적 하위 경로를 확인해 source main과 gh-pages에 게시한다.
