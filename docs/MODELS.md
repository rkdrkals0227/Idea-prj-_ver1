# 모델 교체 안내

실제 업로드 모델은 아직 없습니다. 기본 도형으로 전체 활동이 작동합니다.

1. `public/models/school/school.glb` 또는 `public/models/school/scene.gltf` 등을 넣습니다.
2. glTF는 `.bin`, 텍스처 파일을 원래 디렉터리 구조로 함께 넣습니다. 외부 HTTP URL보다 로컬 상대 경로를 권장합니다.
3. `src/data/asset-manifest.json`의 `school.url`을 `models/school/school.glb`로 바꿉니다. 경로는 public 폴더 기준이며 배포 기본 경로를 자동으로 붙입니다.
4. `targetSize`는 바운딩 박스 중 가장 긴 변을 맞출 월드 크기입니다. 중심은 X/Z 원점, 바닥은 Y=0으로 맞춥니다. `groundHeight`로 추가 높이, `rotation`으로 Y축 회전(라디안)을 보정합니다. `position`은 배치 위치입니다.
5. `collision`은 너비·깊이 직사각형이며 모델과 별개로 유지합니다. 나무는 같은 설정을 여러 위치에 사용합니다. 플레이어는 반경 약 0.38의 점유 공간으로 이동합니다.
6. `animations.idle`, `animations.walk`에 실제 클립 이름을 적습니다. 플레이어는 이동에 따라 재생을 전환합니다. 클립이 없으면 회전·가벼운 상하 움직임을 사용합니다. 주민은 idle 재생을 지원합니다.
7. 새 모델에서 크기·바닥·방향·출입문 앞 위치·충돌과 애니메이션을 브라우저로 확인하세요. 파일/외부 리소스 실패 시 해당 모델만 기본 도형으로 대체합니다.

지원 역할: school, library, apartment, house, tree, otter, turtle, crane, postman, player.
주택가 주민 `resident`와 생태 안내원 `manager`는 기본 도형을 유지하는 별도 상호작용 대상입니다.
대화·퀘스트 ID는 모델 경로와 독립적입니다. 교체를 위해 기존 ID를 바꾸지 마세요.

모델 파일은 신뢰할 수 있는 출처에서 준비하고, 텍스처를 1024~2048px 이하로 줄이고 메시 수·폴리곤·투명 재질을 줄이면 수업용 노트북에서 유리합니다.

자동 검사는 존재하지 않는 GLB를 넣은 상황에서 임시 학교와 게시판을 계속 사용할 수 있는지 확인합니다. 실제 업로드 모델의 시각적 크기·방향·걷기 클립 검증은 파일 제공 후 필요합니다.
