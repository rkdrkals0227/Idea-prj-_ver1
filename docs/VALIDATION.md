## 실패 재현과 수정

새 순서 전에는 전설 읽기 ID만 채우면 보상을 받을 수 있었다. 테스트에서 이를 먼저 재현하고 단계·만남 조건을 추가했다. 라이브러리 우회, 다수 가져오기 뒤 내 전시가 밀리는 경우, 지도 약속 누락도 먼저 실패를 확인한 뒤 수정했다. 호수 쉼터가 안내원 자기소개로 묶여 대화창이 남는 오류는 물건 상호작용으로 분리하고 소개 완료 시 기존 창을 닫아 해결했다. 화면 캡처에서 드러난 전시판 가림은 광선 판정 테스트로 먼저 재현했고, 최신 작품을 앞줄 중앙에 배치하여 해결했다.

읽기 전 잠금, 오답·정답·중복 지급, 일반 활동과 작품 저장은 별도 조건으로 검사한다. 전체 동선을 인간이 키보드로 직접 걸은 검증은 하지 않았고, 먼 대상은 테스트에서 좌표를 배치한 뒤 실제 E키·UI로 활동한다. 실제 태블릿 터치·macOS 한글 IME·Safari/Firefox·교실 노트북 FPS는 실기기 확인이 필요하다.
