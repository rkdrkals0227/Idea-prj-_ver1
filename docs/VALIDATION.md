## 실패 재현과 수정

새 순서 전에는 전설 읽기 ID만 채우면 보상을 받을 수 있었다. 테스트에서 이를 먼저 재현하고 단계·만남 조건을 추가했다. 라이브러리 우회, 다수 가져오기 뒤 내 전시가 밀리는 경우, 지도 약속 누락도 먼저 실패를 확인한 뒤 수정했다. 호수 쉼터가 안내원 자기소개로 묶여 대화창이 남는 오류는 물건 상호작용으로 분리하고 소개 완료 시 기존 창을 닫아 해결했다. 화면 캡처에서 드러난 전시판 가림은 광선 판정 테스트로 먼저 재현했고, 최신 작품을 앞줄 중앙에 배치하여 해결했다.

읽기 전 잠금, 오답·정답·중복 지급, 일반 활동과 작품 저장은 별도 조건으로 검사한다. 전체 동선을 인간이 키보드로 직접 걸은 검증은 하지 않았고, 먼 대상은 테스트에서 좌표를 배치한 뒤 실제 E키·UI로 활동한다. 실제 태블릿 터치·macOS 한글 IME·Safari/Firefox·교실 노트북 FPS는 실기기 확인이 필요하다.

## 코드 검토와 범위

별도의 읽기 전용 검토자가 변경 코드를 검토했다. 중요 발견 사항은 회귀 테스트로 고쳤다. 개인 전체 백업은 진행 복원으로 취급하고, 작품 묶음 가져오기와 구분한다.

건물 모델은 32MiB 전송 한도를 초과하여 아직 읽지 못했다. 독립 입구 표지판은 받은 실제 모델로 교체했고 장소 글자를 앞면에 표시했다. 새 건물 모델을 받으면 문·외벽 간판·충돌 정렬을 확인한다. 아래에 실제 업로드 모델 검증을 추가했다.

지역 역사·서식 원문의 미확인 항목은 여전히 교사용 검토 초안으로 숨긴다. 제공된 금호지 설화는 별도의 수업용 이야기로 표시하며 역사·과학 자료와 구분한다. 공유 서버는 연결하지 않았으므로 두 계정의 승인·권한 검증은 실행하지 않았다.


## 2026-10-25 업로드 GLB 연결

18개 원본을 읽어 정적 메시를 약 500(반복 바닥)/2,500(다른 소품)삼각형으로 제한하고 텍스처를 512px로 줄였다. 애니메이션 파일의 스킨과 애니메이션 배열은 보존했다. 받은 원본 합계 378.6MiB, 웹 사본 약 6.9MiB. 주인공·수달·건물 등을 포함한 12개는 파일당 32MiB 전송 한도로 받지 못했다. 사용자가 줄여 다시 첨부하기로 했으며 적용된 것으로 기록하지 않는다.

- 남생이 세 상태 높이 1.5, 학 세 상태 높이 2.0을 실제 GLB 로딩 후 확인했다. 학 대기는 인사 파일에 들어 있는 Idle_15를 사용한다.
- 정상/파손 타일 교체와 수거 물체 숨김은 기존 상태 ID에 연결했다. 보도·잔디·수면·연잎은 InstancedMesh 공유 인스턴스를 사용한다.
- 실제 Chromium 캡처: `models-village.png`, `models-lake.png`. 장소 표지판과 보도가 읽히고 학교 입구·기존 전시대를 유지한다.
- 코드 검토에서 정지 파일만 실패할 때 임시 모형 겹침/인사 정지, 옛 단일 파일 animations.walk 누락을 발견했다. 실패를 재현한 테스트를 추가한 뒤 수정했다.
- 초기 회귀 실행 중 개발 파일 변경으로 일부 검사가 중단되어 해당 결과는 성공으로 세지 않았다. 파일 변경을 마친 뒤 전체 검사를 다시 실행해 모두 통과했다.
- 소프트웨어 WebGL에서는 느린 프레임 때문에 인사가 길어지는 문제를 확인했고 이동과 별개로 애니메이션 시간 간격을 적용했다. 실제 GPU 노트북 성능 측정은 하지 않았다.
- 공개 Pages URL은 이 환경의 네트워크 프록시에서 403으로 차단되어 외부 접속 확인을 할 수 없다. GitHub 배포 브랜치 업로드와 실제 공개 웹 접근 확인은 구분한다.

운영 빌드를 `/Idea-prj-_ver1/` 하위 경로에서 정적 서버로 실행했다. HTTP 200, GLB 요청 18개 모두 200, WebGL canvas 1개, E키로 학교 교실 진입, 브라우저 예외/JS·CSS·GLB 실패 0개를 확인했다. 빌드는 성공했으며 기존 Three.js 청크 500kB 초과 경고는 남아 있다.

최종 실행 결과: `npm test` **22/22 통과**, `npm run test:e2e` **18/18 통과**(Chromium 소프트웨어 WebGL, 9.1분), `npm run build` 성공. 새 브라우저 검사에서 실제 모델의 idle/walk/greet, 인사 완료 후 복귀, 모든 모델/타일 로딩, 길 수리 전후 표시, 수거 물체 숨김, 정지 GLB 실패 후 모형 겹침 방지·인사 복귀·학교 출입을 확인했다. 기존 16개 회귀 검사도 함께 통과했다. 단위 검사 5개는 모델 정규화, 상태 전환, 일부 상태 누락, 정지 파일 실패, 옛 단일 파일 애니메이션 설정을 검증한다.
