  2. 주택가·호숫가 쓰레기 수거/분류, 쉼터, 행동 구별, 연습 표본 인계, 도서관 출입/책장, 한글 편지 입력 중 이동 중지, 초안 복원, 접수 복원, 입력 HTML 문자 그대로 표시.
  3. 1400×1100 그림 → 1024px 축소, 배경/내부 흰 영역 알파 확인, 등록, IndexedDB 복원, 이름·서식지 수정, 마을·지도·도감 ID 일치, 작품 내보내기·삭제.
  4. 깨진 PNG의 오류 안내, 투명 PNG 알파 유지, localStorage 용량 부족 오류 주입과 복구 안내.
  5. 존재하지 않는 GLB에 대한 임시 학교 대체·실내 게시판 계속 작동.
  6. 건물 앞 실제 키보드 충돌, 나무·호수 충돌 영역, 교사 회의 수정 저장·복원, 잘못된 퀴즈 정답 번호 저장 거부.
  7. 이미지 포함 작품 묶음 가져오기, 동일 ID 교체로 중복 방지, 768px 화면 도구 접근, WebGL 컨텍스트 소실 안내.

테스트에서 먼 활동 위치는 플레이어를 해당 좌표에 배치한 뒤 실제 E키/UI를 사용했습니다. 전체 동선을 처음부터 끝까지 사람 손으로 걸은 검증은 하지 않았습니다. 실제 태블릿의 터치·물리 키보드·한글 IME, Safari/Firefox, 실제 교실 노트북의 FPS는 별도 실기기 확인이 필요합니다.

실제 업로드 GLB/glTF·텍스처·애니메이션 파일이 없어 해당 모델의 방향·문 앞 배치·실제 클립은 확인하지 않았습니다. 지역 자료 원문 요청은 네트워크 정책에서 403으로 차단되어 사실·전설·서식 내용은 검토 초안으로 숨겼습니다. 공유 백엔드 미연결이므로 두 계정의 권한·승인 공유 검증은 실행하지 않았습니다. 파일 선택의 촬영 기능은 기기 OS가 제공하는 범위를 사용합니다.
