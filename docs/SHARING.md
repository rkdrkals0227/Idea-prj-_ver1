# 학급 공유 확장 설계 (미연결)

현재 앱은 로컬 개인 체험판입니다. 계정·서버·기기 간 자동 공유·멀티플레이를 구현했다고 표시하지 않습니다. 기존 백엔드나 연결 정보가 없으므로 서버 연결은 보류했습니다.

로컬 저장 어댑터는 `src/storage.js`에 분리했습니다. `artStore.all/put/remove/putMany`와 작품 묶음 가져오기/내보내기를 제공합니다. 수업 자료와 작은 기록도 이 모듈을 통해 읽고 씁니다. 이후 네트워크 어댑터와 인증을 추가할 수 있습니다.

## 서버가 필요한 데이터

| 자료 | 필드 예시 | 서버에서 확인할 범위 |
| --- | --- | --- |
| 학급 | id, teacherIds, invitePolicy | 가입·학급 구성원 인증 |
| 학생 | id, classId, alias | 학급 소속·필요 최소 식별자 |
| 작품 | id, classId, authorId, blobKey, metadata, approvalStatus | 본인 작품 편집, 교사 승인·삭제, 파일 형식·크기 |
| 회의 결과 | classId, revision, content | 교사만 쓰기, 학급만 읽기 |
| 개인 기록 | userId, letters, reflections | 본인만 읽고 쓰기, 작품 공개에서 분리 |

필요 API: 로그인, 학급 가입, 승인 작품 목록, 서명 업로드, 작품 생성/수정/삭제, 교사 승인/반려, 회의 결과의 버전별 읽기/쓰기. 익명 URL만으로 작품 파일을 공개하지 말고 서버에서 접근을 검증해야 합니다. 파일 삭제는 메타데이터와 실제 Blob 저장소를 모두 처리해야 합니다.

승인 전 작품은 작성 학생과 교사만 조회합니다. 교사 UI 구분은 서버 권한을 대체하지 않습니다. JSON 묶음은 공유에 앞서 교사가 내용을 검토하고 별명만 포함하도록 안내합니다. 학급 작품 내보내기는 개인 편지·소감을 포함하지 않습니다. 개인 백업 파일은 비공개 보관용입니다.

연결 후 필요한 검증: 두 브라우저 세션의 학급 소속 확인, 학생 간 수정 거부, 승인 전 파일 접근 거부, 교사 승인 후 목록 반영, 탈퇴·삭제 후 접근 거부, 학급 간 데이터 격리. 실시간 플레이어 멀티플레이는 별도 범위입니다.
