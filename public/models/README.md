# 금산마을 모델

기존 첨부 모델과 추가 우체통의 웹용 사본은 `uploaded/` 아래에 있습니다.
`uploaded/provenance.json`에 실제 첨부 파일명·크기·애니메이션을 기록했습니다.

설정: `src/data/asset-manifest.json`
상세 연결/크기/공유 역할/검증 안내: `docs/MODELS.md`

원본은 수정하지 않습니다. 새 GLB/glTF는 public 기준 상대 경로를 설정하고,
glTF의 외부 텍스처/버퍼는 원래 상대 경로를 유지해 함께 넣습니다.

학교·도서관·아파트는 원본 메시를 보존합니다(텍스처1024px).
주민 NPC는 수달/남생이/학 각각 한 마리만 생성하며, 나머지 인물 역할은 시설로 옮겼습니다.

추가 첨부 `20_우체통.glb`는 `uploaded/mailbox.glb`로 연결했습니다. 원본은 첨부 파일에 그대로 두고 웹용 사본만 단순화/텍스처 축소했습니다. `mailbox` ID의 정면/바닥/크기/충돌 및 재질 조절은 asset-manifest에서 관리합니다.
